## What to clarify before expanding the pitch

| Earlier wording | More accurate description for now |
| --- | --- |
| “Open-source tool” | “Public source code”; choose and document a project license before making a licensed open-source claim |
| “360 degrees of visual freedom” | Adjustable virtual viewpoint around the captured point cloud; surfaces hidden from the Kinect remain missing |
| “Low-cost home-care therapy” | An accessibility goal; current hardware cost, home setup, and clinical suitability still need evaluation |
| “Tested with a PT and a doctor” | The original README acknowledges a PT and a DO; confirm their actual involvement before describing testing or endorsement |
| “Grided Motor Imagery” | The term is **graded motor imagery (GMI)**; ARM should be described as a digital mirror-feedback prototype, not a complete GMI program |

Published GMI research includes laterality recognition, imagined movement, and mirror movement. That context does not validate ARM itself. [Moseley, randomized trial, 2006](https://pubmed.ncbi.nlm.nih.gov/17082465/).
